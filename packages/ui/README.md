# @kasaride/ui

> **Status**: Inactive / Planned (Phase 0 Monorepo Foundation)

## Responsibility
Shared UI design system and reusable presentation component library for all KasaRide applications.

## Planned Exported Components
- `Button`: Primary, secondary, icon, and inline link button primitives
- `Badge`: Status tags (Forest, Gold, Muted, Exception)
- `CarCard`: Fleet card with rating, daily price, features, and availability badge
- `Icon`: SVG vector icon component
- `Logo`: KasaRide brand header logo
- `Header`: Standardized top navigation bar with back button & action slots
- `Page`: Responsive screen container layout
- `BottomNav`: Standardized bottom tab navigation bar

## Note
This shared package is not yet active. Components are currently sourced from `src/components/`.
