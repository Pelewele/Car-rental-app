# @kasaride/admin

> **Status**: Inactive / Planned (Phase 4 Migration Target)

## Responsibility
Future standalone web application dedicated to central logistics, dispatch operations, and telematics monitoring.

## Scope & Screens
- Central Accra delivery dispatch dashboard (`AdminDispatchDashboard`)
- KPI summary cards (Total Jobs, Active, Attention, Completed, Revenue sum in GH₵)
- Multi-criteria job queue filtering (`All`, `Unassigned`, `Active`, `Delayed`, `No Driver`, `No Signal`, `Cancelled`, `Completed`)
- Responsive queue views: Desktop table grid & Mobile card queue
- Detailed job inspector panel: 5-step progress stepper, audit trail history, support dispute tickets
- Administrative dispatch controls: Driver reassignment, traffic delay marking, job cancellation, issue resolution, & telematics error simulation mode

## Note
This workspace app is not yet active. The working prototype currently runs from the root application (`src/App.tsx`).
