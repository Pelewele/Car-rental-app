# @kasaride/driver

> **Status**: Inactive / Planned (Phase 3 Migration Target)

## Responsibility
Future standalone web application dedicated to KasaRide Accra dispatch and delivery drivers.

## Scope & Screens
- Driver DVLA commercial license onboarding & background check verification (`DriverVerificationScreen`)
- Driver Workspace (`DriverWorkspaceScreen`):
  - Station hub header card (Cantonments), driver rating (`★ 4.95`), per-job payout (`GH₵100`)
  - Cantonments sector dispatch job offer acceptance
  - Phase 1: Mandatory 4-item vehicle pickup inspection checklist
  - Phase 2: Live destination navigation map, ETA countdown, traffic delay / signal loss exception reporting
  - Phase 3: Mandatory 4-item renter handover walkthrough checklist & digital signature proof of delivery watermark with GPS verification
- Driver chat & emergency dispatch support helpline

## Note
This workspace app is not yet active. The working prototype currently runs from the root application (`src/App.tsx`).
