# @kasaride/renter

> **Status**: Inactive / Planned (Phase 1 Migration Target)

## Responsibility
Future standalone web application dedicated to vehicle renters in Greater Accra.

## Scope & Screens
- Car discovery, search, location/date filters, popular Accra neighborhood listings (`HomeScreen`, `ResultsScreen`)
- Vehicle specifications, host info, trip policies, delivery add-on selection (`DetailScreen`)
- Identity & license verification (`VerifyScreen`, `OtpScreen`)
- Delivery vs. self-pickup selection, address entry, mobile money checkout (`CheckoutScreen`)
- Booking confirmation (`ConfirmedScreen`)
- Trip management & active rental list (`TripsScreen`)
- Interactive live delivery tracking map & driver ETA monitor (`DeliveryTrackingScreen`)
- 8-angle vehicle damage photo inspector & fuel recorder (`InspectionScreen`, `ReturnScreen`)
- In-app chat, rating/review submission, support & dispute filing (`ChatScreen`, `ReviewScreen`, `SupportScreen`, `DisputeScreen`, `ProfileScreen`)

## Note
This workspace app is not yet active. The working prototype currently runs from the root application (`src/App.tsx`).
