# @kasaride/owner

> **Status**: Inactive / Planned (Phase 2 Migration Target)

## Responsibility
Future standalone web application dedicated to vehicle hosts and fleet owners in Greater Accra.

## Scope & Screens
- Host compliance onboarding status & application verification (`HostApprovalScreen`)
- Accra Vehicle Delivery Jobs Operations dashboard (`OwnerDeliveryJobsScreen`)
- Active job queue filtering (`All`, `Active`, `Exceptions`, `Completed`)
- 5-step delivery progress timeline tracker
- Real-time fleet availability badge status (`Vehicle Available` / `Vehicle Unavailable`)
- Host partner communication, support ticket filing, & dispute reporting
- Host prototype status override controls

## Note
This workspace app is not yet active. The working prototype currently runs from the root application (`src/App.tsx`).
